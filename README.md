# WALKOUT — 일상을 퀘스트로

익숙한 동네를 탐색·운동·문화 미션으로 새롭게 경험하는 WALKOUT 체험 웹사이트입니다.

- 원본 사이트: https://walkout-quest.tobeway-8242.chatgpt.site/
- GitHub Pages: https://omy1359.github.io/walkout/
- 제작: 한양대학교 창업동아리 한양 TEAM02

## 파일 구성

`index.html` 파일 하나에 화면 구조, CSS, JavaScript, 일러스트, 파비콘이 모두 들어 있습니다. 별도의 빌드 과정이나 패키지 설치가 필요하지 않습니다. Google Fonts와 지도 화면, 길찾기 링크는 인터넷 연결을 사용합니다.

## 주요 기능

- 성수·서울숲·한양대의 예시 미션 6개 탐색
- 지역·유형·소요 시간 필터와 키워드 검색
- 미션 상세, 체크포인트, 체험 완료 기록 및 포인트 합산
- 나의 여정, 배지, 랭킹 체험 화면, 개인 미션 초안 만들기
- OpenStreetMap 지도, 카카오맵 길찾기, 요청 시 현재 위치 확인
- 모바일 화면에 맞춘 반응형 탐색 메뉴

## 실행 및 게시

로컬에서 실행하려면 이 저장소 폴더에서 다음 명령을 실행하고 `http://localhost:4173`에 접속하세요.

```bash
python3 -m http.server 4173
```

기존 `omy1359/walkout` 저장소를 새 화면으로 교체하려면 저장소 **최상위의 `index.html`과 `README.md`를 각각 같은 이름의 새 파일로 교체**하세요. 기존 배포 설정이 최상위 `index.html`을 게시한다면 주소는 `https://omy1359.github.io/walkout/`로 유지됩니다. 변경 사항이 반영되지 않으면 저장소의 **Actions** 또는 **Settings → Pages**에서 배포 상태를 확인하세요.

## 체험 버전 안내

미션 기록과 개인 미션 초안은 해당 브라우저의 `localStorage`에만 저장됩니다. 실제 로그인, 서버 데이터베이스, GPS 이동 거리·체류 시간 검증, 사진 AI 인증, 친구 연결, 실시간 랭킹, 리워드 교환은 구현되어 있지 않습니다. 화면의 포인트와 완료 기록은 체험용이며 실제 보상 근거로 사용할 수 없습니다. 위치 확인은 브라우저 권한이 허용된 환경에서만 동작합니다.
