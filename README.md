# WALKOUT — 일상을 퀘스트로

2026년 9월 리디자인. 정적 HTML/CSS/JavaScript로 제작한 반응형 체험 웹앱입니다.

## 실행
`python3 -m http.server 4173`

브라우저에서 `http://localhost:4173`을 여세요. 이 GitHub 업로드용 사본은 원래 `dist/`에 있던 사이트 파일을 저장소 최상위로 옮겼습니다. 사이트의 HTML, CSS, JavaScript, 이미지 내용은 원본과 같습니다.

## GitHub Pages
별도 저장소(예: `walkout-quest`)를 만들고 이 폴더의 파일을 저장소 최상위에 올린 뒤, 저장소 **Settings → Pages → Build and deployment → Deploy from a branch → main / (root)**를 선택하세요.

## 구현 범위
- 지역/카테고리/시간 필터와 텍스트 검색
- 6개 예시 미션, 상세 안내/힌트, 체험 체크포인트와 중복 보상 방지
- 개인 브라우저 localStorage에 체험 기록 및 개인 미션 초안 저장
- 나의 여정, 포인트 합산, 3개 완료 시 배지, 네이티브 공유/클립보드 폴백
- OpenStreetMap 지도, Kakao 지도 길찾기 링크, 요청 시 현재 위치 확인
- 모바일 하단 탐색 메뉴, 접근 가능한 네이티브 대화상자

## 운영 연동이 필요한 기능
실제 로그인, 서버 DB, GPS 거리/시간/체류 검증, AI 사진 인증, 친구 연결, 실시간 랭킹, 리워드 교환은 이 새 웹사이트에 연결되어 있지 않습니다. 기존 API 주소나 계정 설정을 제공받지 않아 실제 인증을 가장하지 않는 체험 흐름으로 구분했습니다. 브라우저 기록은 사용자가 변경할 수 있으므로 실제 보상 근거로 사용할 수 없습니다. 성수 탐색 단서와 포인트/소요시간은 보고서 아이디어를 바탕으로 구체화한 예시입니다.
